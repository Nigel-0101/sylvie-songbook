# 希尔薇 Sylvie · 点歌筏

公开歌单的 feather-v8 初版。五幅横向原画、823 首歌曲、点歌筏和声映集。

本站是无需构建的静态网站。GitHub Pages 发布来源为 `main` 分支的根目录，`.nojekyll` 保证图片和字体按原样提供。CSS、脚本、字体及插画均采用相对路径，兼容项目网址和后续自定义域名。

## 日常更新

- 在 GitHub Desktop 中添加此本地仓库，修改后提交并推送；Pages 将自动更新。
- 歌曲目录为 `songs.json`，投稿为 `submissions.json`。
- 收藏和最近点歌记录保存在观众当前浏览器。管理端尚未接入云端共享数据，当前发布为公开只读展示页。
- 自定义域名需要在 Pages 设置及域名服务商处配置，未确定域名前不要添加 CNAME 文件。

## 验证状态

发布前通过 10 组 DOM 交互检查、57 个正式资源的本地 HTTP 与哈希检查。当前尚未完成真实浏览器视觉验收和中国大陆各运营商的直连实测，不能把部署成功等同于国内访问稳定性已验证。
