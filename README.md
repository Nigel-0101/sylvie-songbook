# 希尔薇 Sylvie · 点歌筏

五幅横向插画、823 首歌曲与声映集。公开网站由 GitHub Pages 托管，当前自定义域名为 `vvsings.com`。

## 点歌与收藏

- 搜索歌名、歌手或页面显示的歌曲编号。
- 点击点歌复制 `点歌 歌名`。随机候选确认后直接复制并关闭，不再弹第二个提示框。
- 收藏与最近点歌保存在各自浏览器，不按 IP 记录，也不在所有观众之间共享。
- 当前管理页仍是本地预览功能，跨设备的云端管理和数据同步尚未接入。

## 展示资源

插画预览、缩略图和小型玉框已内嵌；清晰展示图按需加载。公开页面不再提供展开原图或原图下载入口，本次发布目录已移除五幅原始大图。插画版权归原权利人所有，本仓库未授予再分发或商用许可。

## 维护

本站不需要构建服务。GitHub Pages 从 `main` 根目录发布，保留 `.nojekyll` 和 `CNAME`。资源使用相对路径。歌曲目录是 `songs.json`，投稿是 `submissions.json`。

2026-09-12 已完成真实 Chromium 的复制与粘贴、随机确认、编号搜索、横向翻页检查；检查了电脑和手机视口，以及图片下载失败时的预览保留。手机视口检查不等于手机实机验收，也不代表国内所有网络都已验证。域名 HTTPS 证书仍处于 GitHub 申请流程，HTTP 复制已有兼容处理。
