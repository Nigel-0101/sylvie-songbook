# 希尔薇 Sylvie · 点歌筏

五幅横向插画、823 首歌曲与声映集。公开网站由 GitHub Pages 托管，当前自定义域名为 `vvsings.com`。

## 点歌与收藏

- 搜索歌名、歌手或页面显示的歌曲编号。
- 点击点歌复制 `点歌 歌名`。随机候选确认后直接复制并关闭，不再弹第二个提示框。
- 收藏与最近点歌保存在各自浏览器，不按 IP 记录，也不在所有观众之间共享。
- 云端管理支持专用密钥链接，无需账号登录。公开端读取只读云端歌单；连接不可用时使用最近缓存或本站 songs.json。管理密钥不在本仓库中。
